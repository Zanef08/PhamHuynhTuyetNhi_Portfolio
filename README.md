# Pham Huynh Tuyet Nhi Portfolio

A clean, modern personal portfolio website showcasing the skills, experience, and professional profile of Pham Huynh Tuyet Nhi, a Quality Assurance Engineer based in Ho Chi Minh City.

## Overview

This portfolio is built as a static HTML/CSS project and includes:
- Hero section with professional title and contact links
- Interactive profile card styled as a terminal output
- Skill highlights for QA, automation tools, and development foundations
- Experience timeline with QA accomplishments
- Education and contact sections
- Animated cursor and floating tag background for a polished user experience

## Built With

- HTML
- CSS
- Google Fonts

## Features

- Responsive landing page layout
- Custom cursor and interactive visual effects
- Marquee of technical skills
- Terminal-style profile summary
- Navigation links to page sections

## Project Structure

- `Nhi_Portfolio.html` — main portfolio page
- `styles.css` — site styling and layout
- `assets/` — image and supporting asset files

## How to View

1. Open `Nhi_Portfolio.html` in your browser.
2. If using a local server, serve the folder and navigate to the HTML file.

## Notes

- No build tools or dependencies are required.
- The portfolio is ready to use as a static website or to deploy to GitHub Pages.

## Contact

To update this portfolio, open the HTML and CSS files in a code editor and modify the content or styling as needed.
